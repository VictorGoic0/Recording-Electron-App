# Project Brief: ClipForge

## Project Overview

ClipForge is a desktop video editing application built in a 72-hour sprint (October 27-29, 2025) for a portfolio/assignment submission. The goal is to create a functional video editor that can record screen/webcam, import clips, arrange them on a timeline, and export professional-looking videos.

## Core Requirements

### MVP Checkpoint (Tuesday, October 28, 10:59 PM CT)

- **Desktop Application Launch**: Electron app that builds and runs
- **Video Import**: Drag & drop and file picker for MP4, MOV, WebM
- **Timeline View**: Visual representation with playhead and time ruler
- **Video Preview Player**: Play imported clips with sync audio
- **Basic Trim**: Set in-point/out-point on clips
- **Export to MP4**: Using bundled FFmpeg
- **Native App Package**: Built distributable

### Final Submission (Wednesday, October 29, 10:59 PM CT)

All MVP requirements plus:

- **Screen Recording**: Capture screen with source selection, countdown, pause/resume
- **Webcam Recording**: Capture webcam with preview
- **Multi-Track Timeline**: 2-3 tracks with overlay support
- **Split Functionality**: Split clips at playhead position
- **Error Handling**: Comprehensive user-friendly error messages
- **UI/UX Polish**: Smooth interactions and professional appearance

## Project Constraints

- **Timeline**: 72 hours total
- **Platform**: macOS and Windows
- **Tech Stack**: Electron + React + Bundled FFmpeg
- **No Backend**: All operations local, file-based
- **No Cloud**: No uploads, authentication, or database

## Success Criteria

**Minimum**: MVP complete by Tuesday, core features by Wednesday, working demo
**Target**: All features + polished UI + no critical bugs
**Exceptional**: Core features + multiple stretch goals + real-time PiP recording
